# mem dream（四级漏斗记忆）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 dream 记忆整理从 ovoice 内嵌子系统迁入 mem CLI，按四级漏斗（年/月/日/对话）重组记忆——每级一个独立索引文件，永久归档、逐层下钻；mem 从纯读端升级为读写端。

**Architecture:** 新建 `src-tauri/src/mem_dream.rs`（自建 dream 算法 + LLM + 写盘 + frontier + 跨月年 + 迁移 + 锁），**整体重写、不调** `dream.rs`/`memory.rs`（只参考其实现）；`bin/mem.rs` 加 async `dream` 分支；复用 `history.rs`（读 jsonl + HistoryEvent + marker）、`config.rs`（cache 定位 + api_key）。`mem read` 按粒度路由（YYYY/YYYY-MM/YYYY-MM-DD）。ovoice 内嵌 dream 过渡期不动、并存。

**Tech Stack:** Rust 2021 · tokio（已在 deps）· reqwest 0.12 非流式（已在 deps）· serde_json · crate `ovoice_lib`（mem 共享全部 lib 模块）。

**Spec:** `docs/superpowers/specs/2026-07-30-mem-dream-design.md`（502 行，24 节 + 2 附录）。本 plan 是其实现展开。

      let args: Vec<String> = std::env::args().collect();
      let cache = resolve_cache(&args);
      let clean = strip_loc_flag(&args);
      if clean.get(1).map(|s| s.as_str()) == Some("dream") {
          let code = block_on_dream(&clean, &cache);
          std::process::exit(code);
      }
      let out = dispatch(&clean, &cache);

  fn block_on_dream(args: &[String], cache: &std::path::Path) -> i32 {
      let rt = tokio::runtime::Runtime::new().expect("tokio rt");
      let flags = parse_dream_flags(args);
      let cfg = load_dream_cfg(cache);          // 从 config.json 读 api_key/model/region + 默认 tail/max
      match rt.block_on(async { ovoice_lib::mem_dream::run_dream_to_idle(cache, &cfg, flags).await }) {
          Ok(stats) => { println!("{stats:?}"); 0 }
          Err(e) => { eprintln!("[mem dream] fatal: {e}"); 1 }
      }
  }

      // 遍历找 kind=marker && data.marker=="dream"，取其 data.until_seq；最后一个胜出；无则 0。
